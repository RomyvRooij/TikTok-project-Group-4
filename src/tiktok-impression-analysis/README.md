# TikTok Impression Analysis

#
# Overview
This analysis inspects and analyzes TikTok feed impression data, including:
- Mix of feed sources (followed/recommended/explore)
- Distribution of ranking scores
- Detection of duplicated or malformed impressions

#
# How to Run

#
## Prerequisites
Make sure you have R installed with the following packages:
- `tidyverse`
- `ggplot2`

#
## Installation
```R
install.packages("tidyverse")
install.packages("ggplot2")
