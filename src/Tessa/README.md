# Analysis of the TikTok users dataset
This folder will contain my analysis scripts for the TikTok project.

# How to run the analysis
1. Open the project in Positron.
2. Make sure you are on the correct branch.
3. Run the scripts in this folder from the project root in the following order
    1. Dowloaddata.R
    2. Cleandata.R
    3. Visualize.R
4. Check in the output folder if the ggplot appears correctly
