# AI Usage

We used AI tools (mainly Tilburg.ai and ChatGPT) to help with this project,
so here's an honest summary of how.

## Tools we used

- Tilburg.ai — our main tool, since we already had free access through school.
- ChatGPT — used sometimes as a backup or second opinion.

We just used the normal web chat interfaces, not the API, so we didn't
track specific versions.

## What we used it for

- Writing a first draft of Downloaddata.R
- Debugging errors, like file path issues and missing folders
- Help writing parts of the summary.qmd analysis
- Understanding Git commands we weren't familiar with, like .gitignore
  and how to untrack a file we'd already committed
- Tidying up this README

## How we checked it was right

We didn't just trust it blindly. We ran the scripts ourselves and checked
for errors, looked over the rendered summary to make sure the numbers made
sense, and read through the code before committing anything.
